# DESIGN.md — OSSGrid Design System

## 1. Visual Philosophy & Art Direction: "Open Source Mission Control"
OSSGrid is engineered as an authoritative, acquisition-grade intelligence platform for Linux Foundation mentorships, benchmarked against Linear, Vercel, and Supabase.
- **Palette Foundation**: Midnight Obsidian (`#07090e`), Elevated Slate (`#0c101a`), Card Surface (`#101626`), Hover (`#151d32`).
- **Accent Signals**: Electric Blue (`#3b82f6`), Emerald (`#10b981`), Amber (`#f59e0b`), Purple (`#a855f7`).
- **Precision Sub-Pixel Borders**: `rgba(255, 255, 255, 0.08)` with inset optical highlight (`inset 0 1px 0 rgba(255, 255, 255, 0.05)`).
- **Zero Gimmicks**: Strictly no emojis in control buttons; all iconography uses consistent 1.5px stroke Lucide SVGs.

## 2. Typography
- **Headings**: `Inter`, weights 700 to 900, tracking `-0.02em` to `-0.03em`.
- **Body**: `Inter`, weights 400 to 500, line height 1.6, contrast ≥7.5:1.
- **Data & Measurement**: `JetBrains Mono` with tabular numerals (`font-feature-settings: "tnum"`).

## 3. Core Component Patterns
- **Hero Launchpad**: Unobstructed high-contrast mission headline, 3D orbit globe canvas, and unified HUD telemetry matrix.
- **Contributor Playbook**: Connected 3-stage process rail (01 Target, 02 Engage, 03 Submit) with core program intelligence metrics.
- **Unified Command Toolbar**: Seamless single-bar category pills, live results count, sort selector, and view modes.
- **Dedicated Filter Studio**: Full-height facet rail with search-within-technologies, term year checkboxes, and organization scale grouping.
- **Precision Micro-Histogram**: 5-column activity chart with proportional heights, active term highlighting, hover tooltips, and year labels.
